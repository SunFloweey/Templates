# Coterie Template

People-ops dashboard with overview, team directory, payroll view and animated interactions.

## Stack

- Next.js 16, React 19 and TypeScript
- GSAP entrance and progress animations
- Lucide icons

## Run locally

```bash
pnpm install
pnpm dev -p 3001
```

Open `http://localhost:3001` or use the catalog preview from the parent folder.
